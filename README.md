# 효돈 Hyo-Don

대회 발표용 Toss-style 인터랙티브 프로토타입입니다.

핵심 메시지:

> 소액은 자유롭게, 고액만 자녀가.

## 실행

```bash
npm install
npm run dev
```

## 데모 흐름

- 소액 결제 시연: 행복마트 35,000원 즉시 승인
- 고액 승인 시연: 건강식품 380,000원 자녀 승인 요청
- 이상거래 차단 시연: ATM 2,000,000원 이상거래 경고 후 거절
- 임계값 변경: 승인 기준을 400,000원으로 조정하면 380,000원이 즉시 통과
- 카드 일시정지: 자녀 앱에서 일시정지하면 결제가 처리되지 않음
